01
SKILLS YOU CAN LEARN

进到我们部门，这些技能都能学

五个岗位都可以从零开始。先跟着师兄师姐练，再到真实活动里上手，慢慢找到你最喜欢的位置。

01

音控

把人声、音乐和现场音量调到舒服又清楚。你会从接线、调音台基础和话筒使用学起。

调音台 / 话筒 / 音频
02

灯控

根据节目节奏切换灯光，让舞台该亮时亮、该炸时炸。先认灯位，再学基础编程和现场操作。

灯位 / 编程 / 氛围
03

打碟

学会衔接音乐、抓节拍和控制现场气氛。不是专业 DJ 也能从最基础的按键与节奏开始。

节拍 / 串歌 / 氛围
04

追光

用一束光稳稳跟住舞台上的主角。要练眼力、反应和配合，成就感直接拉满。

跟光 / 预判 / 配合
05

场控

拿着流程、盯住时间、对接台前幕后。哪里需要人，哪里就有场控把现场接住。

流程 / 对接 / 应变

更多幕后岗位等待你来发现

02
DETAILS MAKE THE SHOW

一场精彩演出由许多细节组成

从调音台、灯光控台到舞台、后台与观众席，熟悉每一件设备、每一处场地，才能让演出稳稳发生。
