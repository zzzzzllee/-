# 2026 级招新推文只读公开页与可视化编辑器设计

## 目标

公开推文只负责手机端阅读，不出现任何编辑入口；在线编辑器负责所有文字、图片和装饰素材的修改，并继续通过 Supabase 保存和多人同步。

## 已确认设计

1. 公开页删除内容编辑、图片替换、重播、下载和编辑器链接，只保留相册滑动与视频播放。
2. 工作板块改为音控、灯控、打碟、追光、场控五张技能卡，每张卡包含图片、岗位名和直白介绍。
3. 招新门槛增加高对比重点卡：不用有基础！师兄师姐从 0 讲起，包教包会，不用有压力！
4. 收获板块只写实际好处：技能、朋友、校园经历、综测分、饭票、轻松团建，不再重复工作流程。
5. 白狼和猫头鹰同时出现在首屏与报名区，作为可移动装饰素材。
6. 编辑器新增可视化编辑栏：预览中的所有正文可直接修改和加粗；图片及装饰可拖动；支持置顶、上移、下移、置底和复位。
7. 富文本覆盖和素材布局写入 content.json 的 richText、layout 字段，并随原有云端保存流程同步。
8. 手机端优先：五个岗位单列、相册提示增加距离和高对比提示条、触控目标不小于 44px。

## 验收标准

- 普通公开地址中找不到 editor.html 链接、contenteditable、文件选择器或保存按钮。
- 编辑器中能选中文字加粗、拖动任意图片/吉祥物并改变层级，保存刷新后仍保留。
- 五个岗位均有独立图片与说明。
- 零基础文案在手机首屏后的前半段明显可见。
- 公开页手机宽度无横向滚动，左右滑动相册提示明显且与相册拉开距离。
