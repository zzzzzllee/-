发布到 GitHub 后无需保持电脑开机，手机也可以打开这个编辑器继续修改。

打开公开页面 ↗
第一次使用：先把项目上传到 GitHub Pages。发布完成后，这个网页就是独立的在线编辑器，电脑关机也不影响手机访问。填写仓库信息和 Fine-grained Token 后即可修改文字、图片和二维码；Token 只保存在本次浏览器会话中，不会写入网页或仓库。

GitHub 发布设置

Token 建议只授权这个仓库，并开启 Contents: Read and write。发布完成后可在浏览器退出或手动清除会话。

如果之前保存失败，先点击“测试 GitHub 连接”；成功后再点击“保存并同步到 GitHub”。修改失败时本机草稿不会丢失。
